02 / WHY YIDU

翻譯不只是一句一句換語言。

書籍需要上下文、術語與結構一起被照顧。

01

術語先確認

例如確認 social self-efficacy 是「社會自我效能」後，同一詞義不漂移成「社交自我效能」。

02

兩種書籍格式

EPUB 保留書籍結構；PDF 轉成可重排 EPUB，先檢查文字抽取與掃描品質。

03

Codex 直接執行

使用你的 Codex 登入狀態與額度，不需要另外管理翻譯 API key。

04

可中斷、可驗證

保留工作目錄與 checkpoint，完成後檢查 EPUB 的目錄、章節、metadata 與術語變體。

03 / WORKFLOW

從原書到可閱讀版本。

Yidu 是 Codex 的工作流程，不是把你的書上傳到一個陌生的翻譯網站。

  1. 01
    檢查格式與權利

    保留原檔，不處理 DRM。

  2. 02
    試譯與確認術語

    先看小段結果，再決定是否完整翻譯。

  3. 03
    完整翻譯與續跑

    沿用上下文與已確認 glossary。

  4. 04
    驗證後交付 EPUB

    PDF 的圖片文字與複雜版面可能需要人工處理。
