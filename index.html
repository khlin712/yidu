02 / WHY YIDUTHE SMALL DETAILS MATTER

一本書的品質，
從術語開始。

好的書籍翻譯不只是把句子換成另一種語言，而是把上下文、格式與閱讀節奏一起帶過去。

01⌘

術語先確認

例如確認 social self-efficacy 是「社會自我效能」後，同一詞義不漂移成「社交自我效能」。

看工作流程 ↗
02▤

兩種書籍格式

EPUB 保留書籍結構；PDF 先檢查文字抽取與掃描品質，再轉成可重排 EPUB。

03◌

Codex 直接執行

使用你的 Codex 登入狀態與額度，不需要另外管理翻譯 API key。

04↻

可中斷、可驗證

沿用 checkpoint 與 glossary，完成後檢查 EPUB 目錄、章節、metadata 與術語變體。

03 / WORKFLOWFROM SOURCE TO BOOK

從原書到
可閱讀版本。

Yidu 是 Codex 的工作流程，不是把你的書上傳到一個陌生的翻譯網站。

  1. 01
    檢查格式與權利

    保留原檔，不處理 DRM；只翻譯你有權使用的內容。

  2. 02
    試譯與確認術語

    先看小段結果，確認台灣用詞與關鍵 glossary，再決定是否完整翻譯。

  3. 03
    完整翻譯與續跑

    沿用上下文、已確認的術語與工作 checkpoint。

  4. 04
    驗證後交付 EPUB

    檢查 TOC、章節順序、metadata；圖片文字與複雜版面可能需要人工處理。
